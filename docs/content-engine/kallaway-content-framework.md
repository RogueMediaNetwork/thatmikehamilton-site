# Kallaway Content Framework

Source: Analysis of Kallaway content strategy videos.

Purpose: Incorporate proven storytelling, algorithm, packaging, and social distribution principles into the That Mike Hamilton, Dead Air Cinema, Rogue Music, Paper Trail, and Creation Engine workflows.

## Core Idea

Do not treat content creation as individual videos.

Treat it as a system:

Outlier discovery → audience fit → unique angle → packaging → hook → story → production → distribution → analytics → iteration

## Two Content Games

### 1. Authority / Conversion Game

Goal:
- trust
- expertise
- leads
- products/services

Rules:
- choose topics that help the target audience
- choose topics that demonstrate expertise
- optimize for qualified viewers, not maximum random reach

Use for:
- That Mike Hamilton
- consulting/business content

### 2. Category Virality Game

Goal:
- reach
- subscribers
- broad awareness

Rules:
- broader topic appeal
- stronger curiosity
- novel angles
- shareable ideas

Use for:
- Dead Air Cinema
- Rogue Music
- Paper Trail

## Script Framework

Every script should include:

### Context → Conflict Loop

Avoid long explanations without tension.

Pattern:

Context:
"This is what was happening."

Conflict:
"But then something changed."

Context:
"Here is why it mattered."

Conflict:
"But there was another problem nobody expected."

Repeat throughout the video.

## Hook System

The first seconds must establish:

- why this matters
- why now
- what question must be answered
- what unexpected thing is coming

Rules:

- Start with the payoff or consequence.
- Do not begin with greetings or background.
- Create multiple legitimate open loops.
- Confirm the click promise immediately.

## Storytelling Rules

### Dopamine Ladder

Use progression:

1. Stimulation
2. Captivation
3. Anticipation
4. Validation
5. Affection
6. Revelation

The viewer should continually receive value while wanting the next piece.

### Sentence Rhythm

Avoid AI-sounding narration.

Use:
- short sentences for impact
- medium sentences for explanation
- longer sentences for emotion/context

Vary pacing deliberately.

### But / Therefore Structure

Use conflict transitions:

"But..."
"However..."
"The problem was..."
"That should have worked. But..."

Avoid:

"And then, and then, and then."

## Topic Selection

Before making a video ask:

1. Does this provide real value to the intended audience?
2. Does this demonstrate unique expertise or perspective?

For broad channels:
- maximize topic surface area
- stay inside channel promise

For authority channels:
- maximize audience fit

## Broad + Narrow Content Mix

Use both:

Broad:
- attracts new viewers
- expands discovery

Narrow:
- creates authority
- speaks directly to core audience

Example:

Broad:
"Texas Has an AI Power Problem"

Narrow:
"What ERCOT's New Data Center Rules Actually Mean"

## Visual Hook Rules

The first moments should work visually as well as verbally.

Use:
- surprising imagery
- maps
- numbers
- before/after comparisons
- unusual objects
- documents
- real locations

The viewer should understand the promise even with sound off.

## Authority Signals

Trust is communicated through:

- research depth
- source material
- quality audio
- clear visuals
- confidence
- specificity

For Mike:
- use real experience
- show documents/data
- explain what was researched

## Social Distribution Engine

One research project should create a content package.

Example:

One long-form episode:

→ YouTube episode
→ Shorts
→ Instagram Reels
→ Facebook clips
→ LinkedIn post
→ newsletter/email
→ community post

Do not simply crop the same video everywhere.

Each platform gets a native hook.

## Short-Form Extraction

From every long-form video identify:

1. Broad curiosity clip
2. Strong opinion clip
3. Number/statistic clip
4. Personal consequence clip
5. Authority/research clip

Each gets a different opening.

## Analytics Loop

Review after publishing:

48 hours:
- CTR
- retention
- first 30 seconds
- comments
- subscribers gained
- traffic sources

Decision:

Winner:
- create adjacent videos immediately

Weak:
- analyze packaging/topic/hook before making more

## Permanent Rules

1. Package before production.
2. Write for strangers, not existing fans.
3. Every video needs a clear promise.
4. Every minute should create a reason to continue.
5. Research once, distribute many times.
6. Use AI to accelerate production, not replace originality.
7. Build systems that learn from performance.
